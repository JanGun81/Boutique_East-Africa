# Bilder till showroom

Lägg **alla bildfiler här** (t.ex. JPG, PNG, WebP). På GitHub Pages blir de tillgängliga under samma sökväg som på den statiska sajten.

## Så här länkar du i `index.html`

Om filen heter `baati-sand.jpg` i den här mappen:

```html
<img src="./images/baati-sand.jpg" alt="Baati i sandfärg" ... />
```

**Viktigt:** använd relativ sökväg `./images/...` så det fungerar när sidan hostas på GitHub Pages.

## Tips

- Använd beskrivande filnamn (utan mellanslag eller åäö i filnamn om du vill undvika problem i vissa miljöer).
- Komprimera gärna bilder innan uppladdning så sidan laddar snabbt.
